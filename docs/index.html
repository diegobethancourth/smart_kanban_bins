Rules for the whole project

  • CSS systems are used read-only. Nothing is changed in SALMI, cargar_reportes.html or reposicion_ue.html.
  • The repository is public from the first commit. It holds aggregated, anonymised series only: facility shown as UE-A, no names, endpoints or credentials. Credentials live in .env, which is never committed.
  • Code is written and commented by the team. Every pull request gets one review from another member.
  • Weekly 30-minute check-in (proposed Sunday) against this plan.

Risks and fallbacks

  • Port 8883 blocked on the campus or demo network. Test it in T0.3; fallback is MQTT over secure WebSockets or a phone hotspot.
  • Free-tier limits on EMQX Cloud or InfluxDB Cloud. InfluxDB keeps data for 30 days only, so run a fresh replay in the last week before the demo. Keep message rates low (deadband, heartbeat) and check each plan's limits in T0.2.
  • Live demo failure. The backup video (T4.4) is recorded from the frozen build.
  • Thanksgiving, 26–27 Nov. Little or no work is planned on those two days.
The detection-latency result comes from a simulation, so it measures how early continuous sensing could flag a crossing compared with the report date. Not field performance. State this in the README and in the demo.
